# VaCrochetando

Aplicação web para catálogo e encomendas de peças de crochê.

##

## Sobre o projeto

Sistema desenvolvido em Angular com foco na apresentação de peças, personalização de pedidos e organização de encomendas.

##

## Funcionalidades

* catálogo de peças com filtros
* página de detalhes com imagens e tamanhos
* carrinho de encomendas com customização
* persistência de dados com localStorage
* listagem de aulas

##

## Stack

[![My Skills](https://skillicons.dev/icons?i=angular,ts,html,css)](https://skillicons.dev)

* Angular
* TypeScript
* HTML
* CSS

##

## Como rodar

```bash
git clone https://github.com/GilvanPOliveira/croche-app
cd croche-app
npm install
npm run start
```
